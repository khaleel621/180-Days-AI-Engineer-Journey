## DSA: Frequency Counting, Sets, and Duplicate Detection

Practiced in `02-data-structures-algorithms/arrays/day06-frequency-and-duplicates.py`:

### Frequency counting — `count_frequency(numbers)`
- Start with an empty dictionary.
- Loop over the list once. If the number is already a key, add 1; otherwise set it to 1.
- Example: `[2, 5, 2, 8, 2, 5, 9]` → `{2: 3, 5: 2, 8: 1, 9: 1}`.
- No `list.count()` or `collections.Counter`; the loop shows the counting pattern explicitly.
- Empty list returns an empty dictionary.

### Sets — `sets_demo()`
- `set(numbers)` keeps only unique values.
- Example: `[2, 5, 2, 8, 2, 5, 9]` → `{2, 5, 8, 9}` (displayed order is not guaranteed).

### Duplicate detection — `find_duplicates(numbers)`
- One `seen` set records values seen at least once.
- When a number is already in `seen`, it is a duplicate; add it to the result only once.
- `already_recorded` set makes sure each duplicate appears only once.
- Order follows first repeated detection: `[2, 5, 2, 8, 2, 5, 9]` → `[2, 5]`.
- No `list.count()` or `collections.Counter`.
