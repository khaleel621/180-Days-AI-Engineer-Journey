### Linear Search — `day07-linear-search.py`

- Searches for a target number in a list using a `for` loop.
- Checks each element one by one, starting from index 0.
- Returns the index if the target exists; returns `-1` if not found.
- Works on sorted or unsorted lists.
- Example: `[10, 20, 30, 40, 50]` with target `30` → `30 found at index 2`.
- Time complexity: best O(1), average O(n), worst O(n).

### Binary Search — `day07-binary-search.py`

- Finds a target in a SORTED list by repeatedly halving the search range.
- Uses `low`, `high`, and `mid = (low + high) // 2` inside a `while` loop.
- If `numbers[mid] < target`, search the right half (`low = mid + 1`).
- If `numbers[mid] > target`, search the left half (`high = mid - 1`).
- Returns the index if found; returns `-1` if not found.
- Requires the list to be sorted; otherwise the result can be wrong.
- Example: `[10, 20, 30, 40, 50, 60, 70]` with target `50` → `50 found at index 4`.
- Time complexity: best O(1), average O(log n), worst O(log n).

## Concepts Learned

- Linear search examines every element once: O(n) time, O(1) extra space.
- Binary search halves the search range each step: O(log n) time, O(1) extra space.
- Binary search requires sorted data; linear search does not.
- Best case for both is O(1) (first/middle element found immediately).
- `low`, `high`, `mid`, and the `while low <= high` pattern.
