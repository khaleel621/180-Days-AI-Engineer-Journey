### Bubble Sort — `day08-bubble-sort.py`

- Repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order.
- Uses nested loops: an outer loop for passes and an inner loop for adjacent comparisons.
- After each pass, the largest unsorted element "bubbles up" to its correct position at the end.
- **Optimized:** uses a `swapped` flag. If a full pass makes no swaps, the list is already sorted and the algorithm stops early (best case O(n)).
- Returns a new sorted list; the original list is NOT modified.
- Example: `[5, 3, 8, 1, 2]` → `[1, 2, 3, 5, 8]`.
- Time complexity: best O(n), average O(n²), worst O(n²).

### Selection Sort — `day08-selection-sort.py`

- Divides the list into a sorted part (left) and an unsorted part (right).
- Finds the smallest element in the unsorted section and swaps it into the correct position at the boundary.
- Moves the boundary one step to the right and repeats.
- Always scans the full unsorted portion, so even a sorted list takes O(n²).
- Makes at most n−1 swaps (one per pass).
- Returns a new sorted list; the original list is NOT modified.
- Example: `[64, 25, 12, 22, 11]` → `[11, 12, 22, 25, 64]`.
- Time complexity: best O(n²), average O(n²), worst O(n²).

## Concepts Learned

- Bubble sort compares adjacent elements and swaps them; large elements "bubble up" to the end.
- Selection sort finds the minimum in the unsorted section and places it at the boundary.
- Optimized bubble sort uses a swap flag to stop early on an already-sorted list (O(n) best case).
- Selection sort always takes O(n²) because it scans the full unsorted portion each pass.
- Both implementations return a new list and leave the original unchanged.
- Time complexity: bubble sort O(n)/O(n²)/O(n²), selection sort O(n²)/O(n²)/O(n²).
