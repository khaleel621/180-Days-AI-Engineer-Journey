### Python: List Comprehensions

Implemented and tested two functions in `01-python-fundamentals/day09-list-comprehensions.py`:

1. **`square_numbers(numbers)`** — Returns a new list with the square of every number using `[x * x for x in numbers]`. Example: `[1, 2, 3, 4] -> [1, 4, 9, 16]`.
2. **`filter_even_numbers(numbers)`** — Returns only even numbers using `[x for x in numbers if x % 2 == 0]`. Example: `[1, 2, 3, 4, 5, 6] -> [2, 4, 6]`.

Rules followed:
- List comprehensions used (no `map()` or `filter()`).
- Original input list not modified — a new list is returned.

### DSA: Best Time to Buy and Sell Stock

Implemented `max_profit(prices)` in `02-data-structures-algorithms/arrays/day09-best-time-to-buy-and-sell-stock.py`:

- Single-pass algorithm tracking `minimum_price` and `maximum_profit`.
- For each price: calculate profit, update maximum_profit, update minimum_price.
- O(n) time, O(1) extra space. No nested loops or sorting.
- Examples verified: `[7,1,5,3,6,4] -> 5`, `[7,6,4,3,1] -> 0`, `[2,4,1] -> 2`, `[3] -> 0`, `[] -> 0`, `[1,1] -> 0`.
