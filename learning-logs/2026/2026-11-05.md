### Python: Tuples and Sets

Implemented and tested concepts and exercises in `01-python-fundamentals/day10-tuples-and-sets.py`:

**Tuples:**
- Ordered, immutable collections created with `()`
- Indexing: positive (from 0) and negative (from -1)
- Single-element tuple requires trailing comma: `(42,)`
- Immutability: cannot add, remove, or change items after creation

**Sets:**
- Unordered collections of unique values created with `{}` or `set()`
- Empty set must use `set()` (not `{}` which creates a dict)
- Duplicates removed automatically
- Operations: add, remove, discard, pop, union (`\|`), intersection (`&`), difference (`-`), symmetric difference (`^`)
- Sets do NOT guarantee original ordering

**Exercises implemented:**
1. `tuple_information(items)` — returns `{"count", "first", "last"}`; empty tuple handled safely
2. `remove_duplicates(numbers)` — uses `set()` to remove duplicates; original input not modified

### DSA: Contains Duplicate

Implemented `contains_duplicate(numbers)` in `02-data-structures-algorithms/arrays/day10-contains-duplicate.py`:

- Set-based approach: iterate through list, check if each number is already in a set
- If found in set → duplicate exists → return True
- If loop completes → no duplicates → return False
- Time complexity: O(n), Extra space: O(n)

**Tests:** `test_day10_contains_duplicate.py` — all 9 tests passed.

**Examples verified:**
- `contains_duplicate([1, 2, 3, 1])` → True
- `contains_duplicate([1, 2, 3, 4])` → False
- `contains_duplicate([])` → False
- `contains_duplicate([5, 5])` → True
