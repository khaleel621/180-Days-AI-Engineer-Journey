### DSA: Valid Parentheses using a Stack

Implemented `is_valid(s)` in
`02-data-structures-algorithms/stacks/day12-valid-parentheses.py`:

**Concepts learned:**
- Stack implemented with a Python list.
- `append()` pushes opening brackets onto the stack.
- `pop()` removes the most recent opening bracket (LIFO) when a closing
  bracket appears, and checks the pair matches.
- Empty stack on a closing bracket → `False`; mismatched pair → `False`.
- After scanning all characters, a non-empty stack → `False`; empty stack → `True`.
- Empty string → `True`.
- Supports `()`, `{}`, `[]`.
- No `sorted()`, no regular expressions, no counting instead of a stack.

**Complexity:** Time O(n) - one pass over the string; Space O(n) - stack
may hold up to n opening brackets.

**Tests:** `test_day12_valid_parentheses.py` - all 9 tests passed:

| Expression | Expected |
|------------|----------|
| `"()"` | True |
| `"()[]{}"` | True |
| `"(]"` | False |
| `"([)]"` | False |
| `"{[]}"` | True |
| `"((("` | False |
| `""` | True |
| `"["` | False |
| `"]"` | False |

**Demo verified:** all 9 example cases printed PASS when running the module directly.
