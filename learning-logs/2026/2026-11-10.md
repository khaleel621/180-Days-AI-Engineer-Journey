### DSA: Min Stack (two-stack approach)

Implemented `MinStack` in `02-data-structures-algorithms/stacks/day13-min-stack.py`:

**Concepts learned:**
- Two stacks: `stack` stores all values; `min_stack` tracks minimum values (its top is the current minimum).
- `push(value)`: always appends to `stack`; also appends to `min_stack` when empty or when `value <= current minimum` (the `<=` handles repeated minimums).
- `pop()`: removes from `stack`; also removes from `min_stack` if the popped value equals the current minimum, revealing the previous minimum.
- `top()`: returns the top of `stack` without removing it.
- `get_min()`: returns the top of `min_stack` without using Python's built-in `min()`.
- All four operations run in O(1) time.
- Empty stack: `pop()`, `top()`, and `get_min()` return None consistently.

**Complexity:** Time O(1) per operation; Space O(n) - min_stack may hold up to n values.

**Tests:** `test_day13_min_stack.py` - all 9 tests passed, covering positive numbers, negative numbers, repeated minimums, popping the current minimum, top(), empty-stack behaviour, and a sequence of multiple operations.
