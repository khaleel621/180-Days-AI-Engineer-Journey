### DSA: Next Greater Element (Stack)

Implemented `next_greater_element(numbers)` in
`02-data-structures-algorithms/stacks/day15-next-greater-element.py`:

**Concepts learned:**
- Next Greater Element: the first strictly greater element to the right; `-1`
  when none exists.
- Stack implemented with a Python list (`append()`/`pop()`).
- Traversing the input from right to left.
- Monotonic decreasing stack: each element is pushed once and popped at most
  once.
- Duplicate values: equal values are popped, so the answer is strictly greater.
- The original input list is not modified.
- Time complexity: O(n); Space complexity: O(n).

**Examples verified:**
- `[4, 5, 2, 10, 8] -> [5, 10, 10, -1, -1]`
- `[1, 2, 3, 4] -> [2, 3, 4, -1]`
- `[4, 3, 2, 1] -> [-1, -1, -1, -1]`
- `[5, 5, 5] -> [-1, -1, -1]`
- `[2, 1, 3] -> [3, 3, -1]`
- `[] -> []`

**Tests:** `test_day15_next_greater_element.py` - all 11 tests passed,
covering all required examples, duplicates, empty input, single element, and
input immutability.
