### Python: Object-Oriented Programming — Inheritance, Method Overriding and super()

Implemented and tested `01-python-fundamentals/day16-inheritance-and-method-overriding.py`:

**Concepts learned:**
- Parent and child classes: a child class inherits from a parent class.
- `super()`: calls the parent class `__init__` (used in `Manager` to initialize
  the inherited `name` and `salary`).
- Method overriding: a child redefines a parent method (`Manager.display_details()`,
  `Dog.make_sound()`, `Cat.make_sound()`, `Rectangle.area()`, `Circle.area()`).
- `math.pi` for circle area.
- Each object's attributes are independent: changing one object never affects another.
- Input validation with `ValueError` and clear error messages.

**Exercises implemented:**
1. `Employee(name, salary)` - stores name and salary; `display_details()` prints them.
2. `Manager(Employee)` - inherits name and salary via `super().__init__()`,
   adds `department`, overrides `display_details()` to also show the department.
3. `Animal`, `Dog(Animal)`, `Cat(Animal)` - `make_sound()` overridden to return
   `"Some sound"`, `"Woof!"`, and `"Meow!"` respectively.
4. `Shape`, `Rectangle(length, width)`, `Circle(radius)` - `area()` returns
   `length * width` and `math.pi * radius * radius` respectively.

**Error-handling behaviour (chosen and documented):**
- Invalid input raises `ValueError` with a clear message.
- `Employee`: name must be a non-empty string; salary must be a non-negative number.
- `Manager`: name must be a non-empty string; salary non-negative; department
  must be a non-empty string.
- `Rectangle`: length and width must be positive numbers.
- `Circle`: radius must be a positive number.
- `bool` values are rejected wherever a real number is expected.

covering employee/manager initialization, inheritance, `isinstance` checks,

### DSA: Daily Temperatures (Monotonic Stack)

Implemented `daily_temperatures(temperatures)` in
`02-data-structures-algorithms/stacks/day16-daily-temperatures.py`:

**Concepts learned:**
- Daily Temperatures: for each day, the number of days until a warmer
  temperature; `0` when no warmer day exists.
- Monotonic stack storing indices (not temperatures).
- Left-to-right traversal of the input.
- Result list initialized with zeros.
- The original input list is not modified.
- No nested loops as the main solution (each index pushed once, popped at most
  once).
- Time complexity: O(n); Space complexity: O(n).

**Examples verified:**
- `[73, 74, 75, 71, 69, 72, 76, 73] -> [1, 1, 4, 2, 1, 1, 0, 0]`
- `[30, 40, 50, 60] -> [1, 1, 1, 0]`
- `[60, 50, 40, 30] -> [0, 0, 0, 0]`
- `[30, 30, 30] -> [0, 0, 0]`
- `[30, 35, 30, 40] -> [1, 2, 1, 0]`
- `[] -> []`

**Tests:** `test_day16_daily_temperatures.py` - all 10 tests passed,
covering all required examples, equal temperatures, decreasing input, empty
input, single element, and input immutability.
