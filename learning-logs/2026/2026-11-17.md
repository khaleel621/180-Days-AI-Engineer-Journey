## Concepts Learned

### Python Abstraction
- Abstraction hides implementation details and shows only essential features.
- `ABC` from the `abc` module is the base class for abstract base classes.
- `@abstractmethod` decorator marks methods that subclasses must override.
- An abstract class cannot be instantiated directly (raises `TypeError`).
- Concrete subclasses must implement all abstract methods to be instantiable.

### Sliding Window Maximum
- A monotonic deque stores indices in decreasing order of their values.
- The front of the deque always holds the index of the current window's maximum.
- Indices (not values) are stored so we can check if they're outside the window.
- Each index is pushed and popped at most once → O(n) time.
- Deque holds at most k indices → O(k) space.
