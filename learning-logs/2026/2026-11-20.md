## Day 21 Topics

### Track A — Python: OOP Class Methods and Static Methods
- What class methods are: methods that belong to the class itself, not to any one object; marked with `@classmethod`.
- The `cls` parameter: first parameter of a class method, refers to the class (like `self` refers to the instance); Python passes the class automatically.
- What static methods are: methods that belong to the class but touch neither the class nor any instance; marked with `@staticmethod`; take neither `self` nor `cls`.
- Difference between instance, class and static methods:
  - Instance method (`def method(self, ...)`): works on one object's own data.
  - Class method (`@classmethod def method(cls, ...)`): works on class-level data shared by all objects.
  - Static method (`@staticmethod def method(...)`): a utility that does not use object or class state.
- When to use each:
  - Instance method: when you need the object's own attributes (`self`).
  - Class method: when you need to read/change a class variable or create objects in a special way.
  - Static method: when you need a helper function that does not touch object or class state.
- Practical program: `Student` class with class variable `school_name`, instance method `display_info()`, class method `change_school_name()`, and static method `is_passed(score)`.

### Track B — DSA: Heap and Priority Queue
- What a heap is: a complete binary tree where every parent satisfies a heap property; usually stored as a list; root is index 0.
- Min-heap vs max-heap: min-heap root is the minimum; max-heap root is the maximum. Python's `heapq` only provides a min-heap (simulate max-heap with negated values).
- Python's `heapq` module: `heapify()`, `heappush()`, `heappop()`, `nlargest()`, `nsmallest()`.
- Main problem: Kth Largest Element in an Array (e.g. `nums = [3, 2, 1, 5, 6, 4]`, `k = 2` → `5`).
- Optimal approach: maintain a min-heap of at most k elements; push each number; pop the smallest when size exceeds k; the root is the kth largest.
- Duplicates handled as separate elements; invalid k raises `ValueError`.
- Time complexity: O(n log k); Space complexity: O(k).
