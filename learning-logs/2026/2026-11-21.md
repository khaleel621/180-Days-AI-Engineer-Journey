## Day 22 Topics

### Track A — Python: OOP Magic Methods (Dunder Methods)

- What magic methods are: special Python methods whose names start and end with double underscores (e.g. `__init__`, `__str__`, `__repr__`, `__len__`, `__eq__`, `__add__`).
- Why "dunder": short for "double underscore" (`__init__` = "dunder init").
- You usually do not call them directly; Python calls them for you (`print(obj)` → `__str__()`, `len(obj)` → `__len__()`, `obj1 == obj2` → `__eq__()`, `obj1 + obj2` → `__add__()`).
- `__init__()`: initializer that sets up a new object's attributes.
- `__str__()`: friendly, readable string shown by `print()` and `str()` (for end users).
- `__repr__()`: developer-friendly representation shown by `repr()` (for debugging).
- `__len__()`: length returned by `len()`.
- `__eq__()`: equality comparison used by `==`.
- `__add__()`: addition used by `+` — NOT implemented for `Book` because `book1 + book2` has no clearly defined meaning (would you join titles? add page counts? keep both authors?). A plain function like `book1.pages + book2.pages` is better if you need total pages.
- Practical program: `Book` class with `title`, `author`, `pages`; input validation in `__init__` (TypeError/ValueError for bad types, empty strings, negative pages, floats for pages).

### Track B — DSA: Top K Frequent Elements

- Problem: given an integer array, return the K most frequent elements (e.g. `nums = [1, 1, 1, 2, 2, 3]`, `k = 2` → `[1, 2]`).
- Frequency counting with a dictionary: map each distinct number to how many times it appears; handles duplicates naturally (the result never contains the same number twice).
- Approach 1 — Dictionary + sorting: count frequencies, sort distinct numbers by frequency (highest first), return the first k. Time: O(n + m log m), Space: O(m) (n = len(nums), m = distinct elements).
- Approach 2 — Heap with `heapq`: count frequencies, keep a min-heap of at most k `(frequency, number)` pairs; pop the smallest frequency when the heap exceeds k. Time: O(n + m log k), Space: O(m) for the dictionary + O(k) for the heap.
- Duplicates handled correctly; negative numbers work as dictionary keys.
- Invalid k (non-integer, < 1, or > number of distinct elements) raises TypeError/ValueError.
- Ties: when several numbers share a frequency, any valid set of k numbers is correct; tests compare results as sets.
