## Day 23 Topics

### Track A — Python: OOP Composition

- What composition is: one class (the "whole") holds an object of another class (the "part") as an attribute — a "has-a" relationship (e.g. a Car has an Engine, a Library has Books).
- Why we use composition: code reuse, small focused classes, loose coupling, and the ability to swap parts at runtime.
- Inheritance vs composition: inheritance is an "is-a" relationship (tightly coupled); composition is a "has-a" relationship (loosely coupled). Prefer composition unless there is a clear "is-a" relationship.
- How one class contains an object of another class: create the part object inside the whole class's `__init__` and store it as `self.<attribute>`, then call the part's methods from the whole.
- Real-world examples implemented: Car + Engine, Library + Book, Student + Address, Room + Lamp + Fan.
- Practical exercises included (Wallet/Person, Team/Player, Department/Employee, engine swap) — learner practice pending.

### Track B — DSA: Binary Trees — Introduction and Traversals

- What a binary tree is: a hierarchical structure where each node has at most two children (left and right).
- Root (no parent), parent (has children), child (connected below a parent), leaf (no children).
- Height (edges on longest path down to a leaf) and depth (edges from root to a node).
- Inorder traversal (Left, Root, Right), Preorder traversal (Root, Left, Right), Postorder traversal (Left, Right, Root) — each implemented as a separate recursive function.
- Example tree used:
      1
     / \
    2   3
   / \
  4   5
  - Inorder:  [4, 2, 5, 1, 3]
  - Preorder: [1, 2, 4, 5, 3]
  - Postorder:[4, 5, 2, 3, 1]
- Edge cases covered: empty tree, single-node tree, larger tree; height and depth functions included.
