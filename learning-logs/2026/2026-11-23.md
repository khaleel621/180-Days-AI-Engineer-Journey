## Day 24 Topics

### Track A — Python: Modules and Packages

- What a module is: a Python file (.py) containing variables, functions, classes you can reuse.
- Why we use modules: reuse, organization, maintainability, collaboration.
- Creating our own module: any .py file is a module.
- Importing modules with `import`: load the whole module/package, call with `module.function()`.
- Importing specific functions with `from ... import`: bring names directly into your file.
- Aliases with `as`: give an imported name a shorter/different name.
- What a package is: a folder of modules marked by `__init__.py`.
- Module vs package: module = single .py file; package = folder of .py files.
- Understanding `__init__.py`: makes a folder a package and re-exports useful names.
- Organizing a small project: `day24_shop/` package with `products.py`, `billing.py`, `receipt.py`; `billing.py` imports from `products.py` inside the same package.
- Day 14 taught importing from ONE custom module; Day 24 builds a whole PACKAGE of modules that import from each other.
- Common beginner mistakes: ModuleNotFoundError (wrong folder), forgetting `__init__.py`, circular imports, `from module import *`, confusing module vs package.

### Track B — DSA: Binary Search Trees — Search and Insertion

- What a BST is: a binary tree with an ordering rule.
- Binary tree vs BST: BST values are ordered; binary tree has no ordering rule.
- BST ordering property: left subtree values <= node.value < right subtree values.
- Documented duplicate rule: equal values go to the LEFT subtree.
- Search: skip one subtree each step using the ordering property; returns node or None.
- Insert: follow the search path; `insert(None, value)` creates a new single-node tree.
- Recursion: each call handles one node then recurses on one child; base case is None.
- Time complexity: O(h) where h is tree height; balanced = O(log n), skewed = O(n).
- Extra space: O(h) for recursion call stack.
- Edge cases: empty tree, single node, missing value, duplicates, negative numbers/zero.
- Inorder traversal verifies sorted order (Left, Root, Right).
